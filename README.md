# $UNCLE - Solana's Chillest Unicorn

A meme coin landing page built with Next.js, featuring a cartoon-style design inspired by BoJack Horseman.

## Features

- 🦄 Cartoon-style design with custom typography
- 📱 Fully responsive layout
- 🎨 Smooth animations with Framer Motion
- 🎯 Modern UI with Tailwind CSS
- 🔗 Integration with Pump.fun

## Tech Stack

- **Next.js 14** - React framework
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **Google Fonts** - Custom typography (Fredoka One, Bungee)

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd unc
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

### Vercel

The easiest way to deploy is using [Vercel](https://vercel.com):

1. Push your code to GitHub
2. Import your repository in Vercel
3. Vercel will automatically detect Next.js and configure the build settings
4. Deploy!

### Manual Build

```bash
npm run build
npm start
```
